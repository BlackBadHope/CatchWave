# Участие в разработке

Изменения принимаются на условиях GPL-3.0-or-later, совместимых с лицензиями исходных компонентов. Сохраняйте атрибуцию и сведения о происхождении кода; не добавляйте чужой код без совместимой лицензии.

Для сообщения об ошибке укажите версию приложения/Android, модель устройства, выход звука, режим Live или обычный подхват, ожидаемое и фактическое поведение. Для проблемы каталога полезна публичная ссылка на запись.

Перед публикацией диагностического фрагмента удалите серийные номера, токены, аккаунты, сетевые адреса и посторонние уведомления. Не прикладывайте личную аудиозапись или полный logcat. Проблему безопасности с секретными данными следует сообщать через доступный приватный канал GitHub, а не публичный issue.

Для изменения алгоритма добавьте целевой регрессионный пример с положительным и отрицательным случаем. Тесты, связанные с каверами и метаданными, должны сохранять защиту от выбора другой записи.

```sh
./gradlew :app:testDebugUnitTest :app:lintRelease :app:assembleRelease
```

Сетевые и телефонные пробы запускайте отдельно и с конкретным пределом времени. Не представляйте успешный unit-тест или совпавший таймкод MediaSession как измерение акустической точности. В pull request укажите выполненные проверки и то, что осталось непроверенным.

Не добавляйте в Git ключи подписи, local.properties, дампы телефона, записи микрофона и build/cache каталоги.
