# CatchWave: быстрый старт бета-теста

Комплект: **Windows Host 0.1.46** и **Android 0.1.45, code70**. Android в этой бете не менялся. Клиент — Android 11+; Host — Windows x64. Проверенный комплект: Windows 11 и OnePlus 12 с Android 16. Остальные телефоны и длительная работа требуют проверки.

## Первое подключение по Wi-Fi

1. Установите APK обычным способом. Распакуйте ZIP Host целиком и откройте `Start-CatchWave.cmd`. Если CatchWave уже установлен, обновляйте поверх с сохранением данных.
2. Телефон и ПК должны быть в одной доверенной локальной сети. Если Windows спрашивает разрешение брандмауэра, выберите нужную частную сеть.
3. В Host откройте **«Источник звука»**. Оставьте **«Windows по умолчанию»** или выберите доступный выход: монитор, наушники, цифровой или уже установленный виртуальный выход.
4. В **Параметры Windows → Система → Звук** направьте звук на этот же выход. Для одного проигрывателя можно использовать микшер громкости Windows. CatchWave захватывает выбранный выход, но сам не перенаправляет на него игры и браузеры.
5. На телефоне откройте **«Звук с ПК» → «Сканировать QR»**, отсканируйте QR текущего Host и подтвердите подключение. Включите музыку на ПК, начните с умеренной громкости телефона и убедитесь, что слышите её.

Физические колонки на выбранном выходе не обязательны, если Windows оставляет выход доступным. Серые устройства «не подключён / выключен / отсутствует» использовать нельзя. При отсутствии звука проверьте, что проигрыватель отправляет звук именно на выбранный выход.

Если Host сообщает о неподдерживаемом формате, в свойствах выбранного выхода Windows задайте **2 канала, 48 000 Гц** (16 или 24 бита), затем повторите подключение. Сейчас поддерживаются моно/стерео и 44,1 / 48 / 96 кГц; автоматического преобразования частоты и многоканального звука нет.

Для смены источника нажмите **«Отключиться»** на телефоне, выберите другой выход в Host и Windows, затем снова подключитесь. Перезапуск Host не нужен. Выбор сохраняется; исчезнувшее устройство не подменяется другим. Перезапуск самого Host меняет приватный QR.

## Кабель и управление

USB передаёт звук через AOA/WinUSB, без отладки Android и режима модема. Начните тестирование с Wi-Fi: установка USB на совершенно чистом ПК и другом телефоне ещё не подтверждена. Подробности и штатные запросы установки — в [USB-SETUP.md](USB-SETUP.md). Не заменяйте все драйверы телефона и не отключайте проверку подписи ради теста. На уже настроенном порте Host может подключать знакомый телефон автоматически; холодный или вручную остановленный сеанс требует одной USB-кнопки на телефоне.

Звук работает отдельно от жестов. Для управления сверяйте ключ телефона в диагностике и разрешайте его на ПК, затем включите **«Разрешить жесты»** и нажмите **«Активировать управление»** на телефоне. Подержите спокойно 1,5 секунды. Наклоны меняют громкость телефона; 3 постукивания — пауза/старт, 4 — следующий, 5 — предыдущий, 6 — выключить/вернуть звук телефона. Между сериями делайте паузу. Обычное движение может вызвать команду: выключайте режим, когда управление не нужно.

## Что проверить и сообщить

- Слышен ли звук с выбранного выхода; сохранился ли выбор после закрытия Host.
- Продолжается ли звук с выключенным экраном; нет ли обрывов.
- Видео на телефоне получает приоритет, после его остановки звук ПК возвращается. Короткое уведомление должно приглушать поток; это ещё требует наблюдения на устройстве.
- «Отключиться» действительно останавливает поток и не запускает его снова.
- Для настроенного USB: слышен ли звук и возвращается ли Wi-Fi после снятия кабеля.

При ошибке экспортируйте встроенную диагностику и укажите, что сделали перед ней, транспорт и версии. Не отправляйте живой QR, ключи, полные системные журналы или личное аудио. Журнал содержит ограниченные счётчики и коды, без записи звука. Собственный виртуальный выход CatchWave и качество на уровне AudioRelay в этой бете не заявляются.
