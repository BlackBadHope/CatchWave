# Подготовка к Play — не публикация

Это чеклист на потом. APK в Play Console из этого коммита не загружался.

## Data safety (черновик)

- Приблизительное местоположение: нет
- Имя, email, телефон: нет
- Рекламный ID: нет (`AD_ID` снят из манифеста)
- Аналитика / Firebase / AdMob: нет
- Аудио: обрабатывается на устройстве; отпечаток уходит в Shazam
- Резервное копирование: выключено

Политика для витрины: [PRIVACY.md](PRIVACY.md). Для Play нужна публичная HTTPS-страница (например GitHub Pages с этим текстом).

## Что ещё не готово к витрине

- Подпись debug-ключом; для Play нужен отдельный upload key, не из репозитория.
- `applicationId` `app.catchwave` стоит сменить на уникальный **до первой** загрузки в Play, иначе пакет займут.
- Распознавание и каталог идут через неофициальные интерфейсы Shazam и YouTube Music. Ревью Play может отклонить это как несанкционированное использование сервиса. Это не закрыто кодом 0.1.10.
- «Уточнить по звуку» использует MediaProjection только для аудио YouTube Music; кадры не захватываются. В анкете Play это нужно явно описать.

## Реклама продукта

Пара тысяч гривен — на продвижение витрины (поиск, соцсети), не на SDK внутри приложения. Встроенная реклама и GAID сломают заявленную прозрачность. Не подключать AdMob «на всякий случай».
