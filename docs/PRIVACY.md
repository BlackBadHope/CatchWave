# Данные CatchWave / Подхват

Приложение не собирает рекламный идентификатор (GAID), не подключает аналитику, Firebase, AdMob и не создаёт аккаунт CatchWave.

## На устройстве

- Аудио микрофона и внутренний звук YouTube Music живут только в оперативной памяти на время распознавания или «Уточнить по звуку».
- Диагностический буфер — RAM, до 80 строк, на диск не пишется.
- `allowBackup=false`, облачный backup и device transfer исключены.
- UUID в запросе каталога одноразовый на запрос, это не идентификатор устройства.
- Приложение Shazam на телефоне не требуется и не запускается.

## Сеть (только HTTPS)

| Куда | Что | Зачем |
|---|---|---|
| `amp.shazam.com` | звуковой отпечаток | каталог (не приложение Shazam): название, исполнитель, оценка таймкода |
| `music.youtube.com` | название и исполнитель | поиск записи для выбранного плеера YouTube Music |

Запуск записи идёт через нативную медиасессию YouTube Music. Разрешение доступа к уведомлениям нужно только для этой сессии; текст уведомлений не читается.

Shazam и YouTube видят IP-адрес. Это обработка на их стороне, не наш сбор.

## Чего нет

Рекламный ID, встроенная реклама, аналитика, crash SDK, свой сервер, продажа данных.
